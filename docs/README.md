# yatmux docs

This folder documents **yatmux** configuration: where it lives, how it’s loaded/merged, and the exact defaults.

## Quick start

- First run auto-creates a commented config template (when a config directory can be determined).
- Edit the config file, then restart yatmux or use **Reload config** (default: `ctrl+shift+r`).

## Docs index

- `docs/usage.md` — everyday usage: mouse, search, tabs/splits, URLs, scrollback.
- `docs/config.md` — config file location, merge/precedence rules, schema, defaults, and value clamps.
- `docs/keybindings.md` — keybinding format, how to override/disable, and the full default bindings.
- `docs/themes.md` — built-in + custom themes, theme file format, and precedence.
- `docs/shell-integration.md` — OSC 7 / OSC 133 integration and how to enable it (bash).
